# Prompt inicial para o GitHub Copilot

Leia com atenção `README.md`, `.github/copilot-instructions.md` e os
documentos dentro de `docs/`.

Estou desenvolvendo sozinho, com orientação de IA, o sistema **Passagem
de Serviço --- ABM**. Quero aprender a construir e manter o sistema,
então trabalhe em etapas pequenas e explique as decisões em português
brasileiro.

O projeto Next.js está apenas no scaffold inicial e executa localmente.
As funcionalidades descritas nos documentos existem como referência nos
protótipos HTML anteriores, principalmente na versão v0.6; elas ainda
não foram implementadas no Next.js. Não presuma que há banco,
autenticação ou integração Supabase configurados.

**Primeira tarefa:** inspecione a estrutura real do repositório e o
`package.json`. Compare o estado atual com a documentação e me diga: 1.
O que já existe e está funcionando. 2. O que ainda não existe. 3. Qual é
a menor próxima etapa recomendada. 4. Quais arquivos essa etapa afetaria
e como eu a testaria.

Não implemente o sistema inteiro de uma vez. Não instale dependências,
configure serviços externos, crie banco de dados ou altere arquivos em
massa sem antes explicar o motivo e obter minha confirmação. Use apenas
dados fictícios. Não copie dados reais de planilhas ou comprovantes para
código, seeds ou prompts.
